# Piik Desktop v0.1.0

First public release.

## Downloads

- Windows x64: NSIS installer.
- macOS Intel x64: DMG and application ZIP.
- macOS Apple Silicon arm64: DMG and application ZIP.
- Source archive and SHA-256 checksums.

## Highlights

- Local Room, Public Invite and Connect to Site.
- English/Chinese, light/dark themes and recent sites.
- Native window/screen/camera source selection and source-card previews.
- Create link / Rotate link labels reflect invitation state.
- Fixed clipboard copying, connection loading and desktop-only source tabs.

## Validation

39 tests pass. macOS x64 and arm64 compile successfully in CI; package architectures have been checked to match their Core and capture helper. Physical macOS camera/audio/permission behavior still needs device testing.

These are unsigned community builds, powered by Piik v1.9.2 from TNTcraft and contributors.
